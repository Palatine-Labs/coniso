# Quiet run

Work silently. Between tool calls, write nothing: no narration of what you are about to do, no restating of tool output, no running commentary. Everything you write stays in the session's context for every later turn, so unneeded prose costs tokens all session long.

Speak only for:
- a one-line status after a unit of work completes (for Coniso, the per-wave status line);
- a decision or question that needs the user (FLAGS, gates, permissions);
- an error you cannot resolve yourself;
- the final report.

Keep those short and concrete. When the user asks a question directly, answer it normally.
